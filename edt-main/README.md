# EDT Project

This project was developed  during our first Master year in ENS de Lyon. It implements an interface and a solver for an app that generates timetables for Schools.  

## How to

We use [Custom Tkinter](https://customtkinter.tomschimansky.com/) to build our app and [pychoco](https://github.com/chocoteam/pychoco) as a solver. To install them :

- Custom Tkinter : ```pip install customtkinter```
- Pychocco : ``` pip install pychoco```

Once this is done you can launch the app :
On Linux/Macos : launch run.sh
On Windows : launch run.exe (NOT DONE YET)

If for any reason it doesn't work launch [main.py](/code/main.py)
